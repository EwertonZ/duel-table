# DUEL TABLE - ONLINE

This project is a web online table that allows card game players to play Yu-Gi-Oh or another card game in the future,
like they were playing in real world.

The Duel table does not implement the game or deck construct rules.
It just lets the players to get cards and put them on the table, along with HP counter
that must be manually updated.

I will add more description as the project grows.
